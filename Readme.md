# ❌ Custom 404 Error Page

A beautifully animated and responsive **404 Error Page** built using **HTML**, **TailwindCSS**, and a **background GIF**. Designed to enhance user experience when navigating to a broken or missing link.

## 🚀 Features

- ⚡ Animated background with a smooth floating SVG icon
- 🌈 TailwindCSS for responsive design and styling
- 🎨 Dark overlay for better text readability
- 🧭 "Go Back" button to return to the previous page
- 📱 Mobile-friendly layout

## 📦 Deployment on Vercel

1. Push the code to a GitHub repo (e.g., `404-error-page`)
2. Go to https://vercel.com/new
3. Import your GitHub repo
4. Choose **Framework: Other / Static**
5. Deploy and get your live link
